# Support and maintainers

searsuite-website is maintained by the [SearSuite organization](https://github.com/SearSuite). The current maintainers are the organization owners and repository collaborators.

- Usage questions and bug reports: [open an issue](https://github.com/SearSuite/searsuite-website/issues) in this repository and include a minimal reproduction.
- Feature ideas: [open an issue](https://github.com/SearSuite/searsuite-website/issues) and describe the use case.
- Contribution process: see [CONTRIBUTING.md](CONTRIBUTING.md).
- Security-sensitive reports: use a private reporting channel if one is published on the maintainer profile or in the repository Security tab. Otherwise, open an issue requesting a private channel without including exploit details.

This project does not currently promise response times, long-term maintenance for older versions, or commercial support.
