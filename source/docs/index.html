SearSuite provides composable spreadsheet modules for applications where people and AI agents edit through a shared model. Sheet state, commands, rendering, platform adapters, and optional features have explicit boundaries, so you can choose and replace the pieces your product needs. The code is currently written in TypeScript; those same contracts provide a path to other runtimes.
