Get started with SearSuite

SearSuite provides TypeScript modules for building spreadsheet experiences that people and AI agents can edit together. Install the public packages from npm and run an editable spreadsheet in your browser.

Install from npm

Use Node.js 22.12 or later. Create a Vite application with the vanilla TypeScript template, then install the Sheet editor and browser packages. No repository checkout is required. 

npm create vite@6 my-searsuite-app -- --template vanilla-ts
cd my-searsuite-app
npm install
npm install \
  @searsuite/sear-assembly-setup@0.0.1 \
  @searsuite/sear-browser-adapters@0.0.1 \
  @searsuite/sear-plugin-web-toolbar@0.0.1 \
  @searsuite/sear-plugin-sheet-doc-adapter@0.0.1 \
  @searsuite/sear-render-scroll@0.0.1

For an existing application, run only the install command in its project directory. When adding other @searsuite/* packages, use the same release version.

Create the page

Replace index.html with the following page. The toolbar has its own container, and the Canvas provides an 800 by 480 pixel editing surface. 

<!doctype html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>SearSuite</title>
    <style>
      body { margin: 0; }
      #canvas { display: block; width: 800px; height: 480px; }
    </style>
  </head>
  <body>
    <div id="toolbar"></div>
    <canvas id="canvas"></canvas>
    <script type="module" src="/src/main.ts"></script>
  </body>
</html>

Create the editor

Replace src/main.ts with this code. It supplies the browser adapters, creates the Sheet editor, and mounts its toolbar. 

import {
  createEmptySheetDocumentState,
  createSheetEditor,
  SheetRuntimeCapability,
} from '@searsuite/sear-assembly-setup';
import {
  BrowserPlatform,
  WebCanvasRenderContext,
  WebCursorEngine,
  WebEventRegistrar,
  WebKeyboardRouter,
  WebPointerCapture,
  WebScroller,
  WebSocketTransport,
  WebTextInput,
} from '@searsuite/sear-browser-adapters';
import { SearWebToolbar, WebSheetAdapterDefaults } from '@searsuite/sear-plugin-web-toolbar';
import { createSheetEmbeddedSearCoreEditor } from '@searsuite/sear-plugin-sheet-doc-adapter';
import { Scroller } from '@searsuite/sear-render-scroll';

const canvas = document.getElementById('canvas') as HTMLCanvasElement;
const editor = createSheetEditor({
  viewport: { width: canvas.clientWidth, height: canvas.clientHeight },
  sheetState: createEmptySheetDocumentState(100, 26),
  embeddedEditor: createSheetEmbeddedSearCoreEditor(),
  adapters: {
    ...WebSheetAdapterDefaults,
    platform: BrowserPlatform,
    createRenderContexts() {
      const context = new WebCanvasRenderContext(canvas, false, new BrowserPlatform());
      return {
        renderContext: context,
        offScreenRenderContext: context.cloneNode(),
        hitRenderContext: context.createHitNode(),
      };
    },
    scroller: WebScroller,
    eventRegistrar: WebEventRegistrar,
    textInput: WebTextInput,
    keyboardRouter: WebKeyboardRouter,
    pointerCapture: WebPointerCapture,
    cursorEngine: WebCursorEngine,
    collabTransport: WebSocketTransport,
    toolbar: SearWebToolbar,
    registerEnvironment(container) {
      container.registerInstance(Scroller.ContainerSymbol, canvas);
      container.registerInstance(WebKeyboardRouter.eventTargetSymbol, document);
      container.registerInstance(WebPointerCapture.eventTargetSymbol, document);
    },
  },
});

editor.services.require(SheetRuntimeCapability.Toolbar).mount(document.getElementById('toolbar'));

if (import.meta.hot) {
  import.meta.hot.dispose(() => editor.destroy());
}

The editor runs locally. Providing WebSocketTransport does not open a collaboration connection; this setup does not require a collaboration server. In an application, call editor.destroy() when the editor view unmounts.

Start the application

npm run dev

Open the URL printed by Vite. Select a cell and type to edit it, or double-click a cell to open its editor. See the host application guide and API reference for further integration.
